# כלומיון — תאגיד הפתרונות הכוללים

> "עוסקים בהכל. מבינים פחות."

## מה זה כלומיון?

כלומיון היא חברת הייטק וירטואלית עם 240+ אגפים. כל אגף עוסק במשהו שונה לחלוטין, הלינקים חלקם שבורים בכוונה, והמוצר הוא האתר עצמו.

זה גם פרויקט לימוד הייטק — מי שמצטרף לכלומיון מקבל טיקטים אמיתיים, עושה פול ריקווסטים אמיתיים, ומשתמש בגיטהאב כמו בחברה אמיתית.

## איך להצטרף

1. פתח את [דף המועמדות](careers.html)
2. מלא את השאלון
3. קבל טיקט מהמנכ"ל
4. תרום תוכן לאגף שלך דרך Pull Request

## איך לתרום

כל אגף הוא קובץ HTML נפרד בתיקיית `agafim/`.

```
agafim/
  mishpat.html      — אגף משפט
  parot.html        — אגף הפרות
  kabala.html       — אגף קבלה
  ...
```

כדי להוסיף אגף:
1. צור קובץ חדש בתיקיית `agafim/`
2. העתק את התבנית מ-`agafim/template.html`
3. מלא תוכן (מלל מגונרט מתקבל בברכה)
4. פתח Pull Request

## כלל אחד

הלינקים השבורים הם לא באגים. הם פיצ'רים.
